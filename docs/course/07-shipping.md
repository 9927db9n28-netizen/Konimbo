# משלוחים (21 מאמרים)

## שלוש שיטות (נבחרת ברמת החנות)
1. **ברירת מחדל + ייחודי** (ברירת המחדל של המערכת): ברירת מחדל = משויך אוטומטית לכל מוצר; ייחודי = משויך ידנית (עריכת מוצר > משלוחים / עדכון גורף סעיף **27** "הצג משלוחים"; סעיף 26 = עדכון משלוח ייחודי בודד רק אם כבר משויך אחד).
2. **לפי סכום עגלה** (דגל 46, דרך התמיכה — **עלול למחוק משלוחים קיימים**): לכל משלוח מינימום/מקסימום סכום; **חובה לכסות 0 עד 9999999999 ברצף** (מקסימום של א' = מינימום של ב'). לפני הנחות — דגל 124.
3. **לפי משקל עגלה** (דגלים 47/140): אותו עיקרון בק"ג; משקל המוצר בלשונית "יתר".
- בכל שיטה אפשר גם "משלוח למוצרים — לא לפי סכום/משקל" (ייחודי).

## שדות משלוח (הגדרות > משלוחים, `admin/shipping_option_topics`)
כותרת, מחיר, **סוג** (איסוף עצמי — לא מוצג בזאפ/בדף מוצר אם יש אחרים, ומציג "קיימת אפשרות לאיסוף עצמי"; boxit; shop&collect), "סמן באדום בכל ההזמנות", מיקום, (סכום/משקל מינ'/מקס'), מק"ט (משלוח כמוצר בהזמנה/API; `ups-pickups` ל-UPS).
- דף מוצר מציג את המשלוח הזול ביותר. לכל מוצר חייב להיות ≥1 משלוח.
- "משלוח ייחודי גובר": מוצגים רק הייחודיים אם אחד מהם יקר ממשלוח ברירת המחדל היקר ביותר (דרך התמיכה); דגל 143 "לא מחמיר"; דגל 144 בלי איסוף עצמי.
- **משלוח לפי מוצר** (דגל 21): משלוח נפרד לכל מוצר; **לא עובד עם HFD/צ'יטה/נקודות איסוף**; דורש משלוח מסוג איסוף עצמי. דגל 22 — כמות משלוח=כמות מוצר.
- **משלוח לפי ערים/אזורים**: הגדרות > משלוחים > משלוח לפי איזור > הוסף משלוח > ערוך (אזורים/ערים) → בעגלה מופיע סלקט עיר. שילוב עם משקל = משלוח נפרד לכל טווח. מומלץ טופס עגלה ארוך.

## חברות שילוח מחוברות
Boxit / Shop&Collect (מזהה לקוח לתמיכה; דגל 101 + אלמנט), **HFD** (E-POST/Door2Door), **צ'יטה** (Cheetah Shops, ~1000 נקודות; עדכון נקודות כל שעתיים, `admin/external_shippings_masters`), **UPS** (הייבריד "הגדרות UPS - דף עגלה", מק"ט `ups-pickups`, "UPS Actions" בהזמנות: Send to UPS/מדבקה), **YDM**, **אוריין**, **DTDC** (דורש API להזמנות + 3 הייברידים + טופס עגלה ארוך), Sosna.

## פיתוחים/הייברידים בעגלה
- "בחר סוג משלוח" ריק כברירת מחדל + התראה (אלמנט).
- סלקט מותנה למשלוחים (שמות "אזור - עיר - שעה", עד 3 רמות; הייבריד duplicate=3339, 1,500 ₪).
- הסתרת שדות כתובת לאיסוף עצמי; הצגת כל המשלוחים בדף מוצר + תיאור (תוסף, ליקוויד `{{item.shippings_sorted_json}}`).
- אפיליאציה לפי משלוח: תבנית מייל שונה לכל משלוח/סניף (+ SMS למנהל סניף) — פיתוח בתשלום.
- ליקוויד סכום עגלה ללא משלוח: `{{cart.show_total_full_price_with_upgrades_and_discounts}}`.
- משלוחים חסרים בפיד/V2 API: לכבות זמנית דגל 46, לנקות שיוך, להחזיר, לנקות קאש.
