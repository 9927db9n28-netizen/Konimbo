# דף הבית, מערכת המודולים, דפי חנות, מערכת אינטגרציות Lambda (18 מאמרים)

## דף הבית
- **סליידר**: הגדרות > אלמנטים בחנות > "דף הבית - סליידר" (חלקים: שם, כותרת, תוכן, כתובת הפנייה, קובץ/לינק, מיקום, ALT, CSS, מחיקה). באתרים חדשים — **הייבריד סליידר**: עד 10 שקופיות; שקופית פעילה, תמונה (≥2000px, עד 12MB), **תמונה למובייל** (≥800px), לינק מלא, ALT, טקסט 1-4 חיים (טקסט 1 = H1 בשקופית הראשונה בלבד); הגדרות קרוסלה (סיבוב אוטומטי, מהירות, הפסקה, עצירה ב-hover, אפקט).
- סליידר "נחתך": האלמנט מיועד לתמונת רקע + טקסט חי; לטקסט בתוך התמונה צריך אלמנט אחר עם תמונות נפרדות לדסקטופ ולמובייל.
- **GUI**: הייברידים ישנים (סליידר/קטגוריות מעוצבות) — להחליף `edit` ב-`gui` ב-URL של `admin/user_files/<id>/` → עורך ויזואלי (תמונה, כותרת, קישור, לכל גודל מסך).
- כותרות קרוסלת מוצרים בדף הבית: אלמנט "גריד מוצרים"/"קרוסלת מוצרים" (`c_x`). מוצרי הקרוסלה מנוהלים בתג.
- **ריווחים בין מודולים**: רוב הריווחים מוגדרים **מתחת** למודול; הייבריד > Design (4 מצבי מסך); `c_x`/`g_x` → layout > main > `margin` (CSS מקוצר); מודול חדש → "מורחב" > עיצוב כללי > ריווחים; מתחת להדר → קאש לשדה "הודעה חשובה בדף הבית". אחר כך **נקה קאש**.
- דילוג על מסך "בחר גרסה" במובייל (אתר קלאסי) — הייבריד duplicate=93814.

## מערכת המודולים החדשה (סרגל ימני)
- **לא תומכת באתרים עם גרסת מובייל נפרדת**; **לא תומכת באימוג'י** (המודול לא יוצג!).
- רשימת מודולים: הצגה/הסתרה, שכפול; "מודול חדש" → תבנית (באנר מתחלף, קרוסלה, מוצר החודש...) או מאפס.
- **שכבות** (עץ): שינוי שם/שכפול/מחיקה/הזזה. לכל שכבה לשוניות: **תוכן** (טקסט; תמונה + ALT + קישור), **עיצוב** (שקיפות, overflow, cover, מסגרת, פינות, צל, צף/z-index, padding/margin), **מעבר עכבר** (טריגר, שקיפות, צבעוני/שחור-לבן, זום/תזוזה/סיבוב, גודל, צל).
- **דסקטופ ומובייל נפרדים** — אייקון המובייל בכל שדה מעתיק למובייל.
- שמירה: **טיוטה** או **שמירה + פרסום**; הגדרות (שם, מיקום, קבוצה, סביבת בדיקות/אתר, פעיל); **היסטוריה** (5 שמירות אחרונות, שחזור).
- תבנית עיצוב חדשה: קובייה 285×285 (או 570×285) ב-Figma כ-SVG → מודול 1×4 → "יצירת תבנית".

## דפי החנות
- דפים > אודות / צור קשר / דפים נוספים (יצירת דף: כותרת, תוכן, דף אבא, תצוגה בחנות, מיקום, css, "הצג תוכן של דף זה ב-URL הזה", קטגוריה, SEO, אלמנטים מחוברים).
- **"הצג תוכן ב-URL הזה"** (קישור יחסי): להחליף כותרת של דף/קטגוריה, או לפצל תוכן קטגוריה עליון/תחתון עם **page break** בעורך.
- דף מעוצב מקוד חיצוני: הייבריד "קובץ חדש עם משתנים" → סימון באלמנט → שיוך לדף.
- דף ארוך שלא נשמר (הגבלת תווים) → לפצל ל"דפים פנימיים" (דף אבא).
- דף כל המוצרים בלי עימוד → דגל "paginate לצורך autoscrolling".

## מערכת האינטגרציות (Lambda) — "פיתוחים מיוחדים"
- אינטגרציה = **הייבריד** עם לשוניות: **משתנים** (נכנסים ל-`{{var_to_json}}`: מיפוי שדות, כתובות, טוקן), **פנימי** (URL של `settings.json` — **למחוק לפני שמירה** כדי לפרסם קוד חדש ל-Lambda; שם משתמש/סיסמה), **כללי** (`javascript_before` = מהלך האינטגרציה).
- מבנה הקוד: `vars`, `log`/`ErrLog` (`types`: s3/console, `save`, `key`), `response`, `actions` (סדר ריצה; `type`: normal/loop; `freeMemory`), `steps` (`dataType` json/xml, `template` = JS עם `return`, `options` Ejs).
- הפעלה: `https://spc4o29rz0.execute-api.eu-west-1.amazonaws.com/production/wakeup?dataIndex=0&subdomain=<sub>&hybridId=<id>&filename=settings.json&token=<token>`; Lambda חי 15 דק' וממשיך מ-`dataIndex`.
- מיילים: משתנים `successEmails`, `errorEmails`, `sendgridSubject`, `sendgridApiKey`.
- דוגמה אמיתית: Priority → מוצרים (ניקוי HTML בתיאור) — שינוי קוד = עריכת ההייבריד + מחיקת ה-URL בלשונית "פנימי".
- זו המערכת החדשה; המערכת הישנה ("אינטגרציות"/"טריגרים" עם Config/Initial Script/Actions) מתועדת ב-GitHub (`integration.md`).

## תוספות מתיקיות קטנות
- **GUI** (Hybrid > עריכת קוד > כפתור GUI): מצבי מסך (כל המסכים / כל פרט למובייל / דסקטופ / לפטופ / טאבלט / מובייל); בחירת מודול → עריכה → **שמור** (ירוק); "הצג שדות לקידום" (tooltip, alt); סליידר: "מיקום החלק" (שומר מיד), "הצג חלק", **הגדרות סליידר** (מספר תמונות ≥2, מספר אייטמים, בולטים, הפעלה אוטומטית, הפסקה בשניות, עצירה ב-hover). אם תמונה לא מתעדכנת ב"כל המסכים" — להגדיר בכל מצב מסך בנפרד.
- **Layout X — קבוצות ומיקום**: דף הבית `homepage_layout_x`, קטגוריה `category_layout_x`, כל המוצרים `layout_items` (בד"כ 4 קבוצות לדף); לכל אלמנט/הייבריד-אלמנט: לייאוט, מיקום (עולה), קבוצה. `c_x`/`g_x` בקבוצת `container`, השאר `container-fluid`. הגדרות: `admin/layoutxs/0/edit`.
- **Quick View** ("מבט מהיר"): התקנה עצמית (לשמור פעמיים), פועל בסאבדומיין מיד ובאתר תוך שעה; מציג רק שדרוגי חובה ומלאי; class `showoneqv` (לשדרוג), `showallqv` / `hideallqv` (למוצר).
- **בלוג מתקדם** (התקנה ע"י התמיכה): קטגוריית בלוג ראשית + תתי קטגוריות, מאמרים (תיאור, תוכן, תמונה ראשית, נלווים, סינונים, מפרסם), הגדרות (זמן קריאה, מפרסם, תגובות פייסבוק, תאריך, קרוסלת מוצרים, מיון, צבע, תבנית). 301 מהבלוג הישן.
- **סוכן Sera AI** (בלוג אוטומטי): מפרסם מאמר כל יום ב-10:00; צריך קטגוריה עם class `articles`; נושא נלקח מהגדרות > כללי סעיפים 25-26 (Google description/keywords של החנות); מצב ידני = מאמר עם קוד גישה `pending`; שגיאת מקסימום מוצרים (10000) → להגדיל.
- **פייפאל**: תעודה חדשה `app_cert.pem` **בתוקף עד 2036** (הישנה פגה באפריל 2026!) — אם פייפאל הפסיק לעבוד באתר, לבדוק החלפת Cert ID.
- **פרטיות ואבטחה**: מבחני חדירה, אימות דו-שלבי (חובה בכניסה מחו"ל), ניתוק אוטומטי, חסימת מדינות עוינות, תוסף חסימת IP, גיבוי AWS, **Konimbo Shield** (HTTPS + CloudFront + WAF).
