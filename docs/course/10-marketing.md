# Marketing Automation (InforU) (23 מאמרים)

## מה זה
מערכת דיוור (מייל + SMS + אוטומציות) של **InforU (InforUMobile)** המשולבת בממשק (כפתור "מערכת דיוור/SMS"; כתובת `automation.konimbo.co.il`).
בהרשמה (עצמאית מהממשק: טופס פרטי עסק + חבילות) המערכת **מייבאת אוטומטית את כל הלקוחות מאושרי הדיוור** מהגדרות > לקוחות, ומתקינה: 9 הייברידים (פופאפ, קוד באתר, נטישת עגלה v2...), 3 משתמשי API, 4 webhooks (`trigger_register`, `trigger_ticket`, `trigger_order`, `trigger_abandoned_order_created_future`).
תמיכה במערכת עצמה: InforU 03-941-5550 שלוחה 2, support@inforu.co.il.

## הקמה נדרשת
- **מייל עסקי על הדומיין** (לא gmail/hotmail). אימות מייל+טלפון בפרטי החשבון.
- דיוור אלקטרוני > כלים > **הגדרות דומיין**: רשומות **SPF / DKIM / DMARC** (כולן בירוק). אם ה-DNS מנוהל בקונימבו (AWS) — התמיכה מעדכנת; דוגמה: `v=spf1 include:_spf.google.com include:smail1018.com ~all`, DKIM `s1._domainkey → s1.dkim.smail1018.com`.
- **שם שולח SMS**: טקסטואלי (למשל "Dynamica") — דורש סרטון זיהוי עם מסמך בעלות; או מספרי — SMS > כלים > "אימות זיהוי שולח מספרי".
- אימות דו-שלבי לכניסה — אפשר להעביר מ-SMS לאימייל (הגדרות > אבטחת מידע).
- חבילות: SMS שיווקי 5,000 ב-150 ₪+מע"מ; SMS אופרטיבי (סטטוס הזמנות, משתמש OPERATIVE דרך חנות התוספים) 1,000 ב-130 ₪+מע"מ. מייל — לפי כמות נמענים (bounce קבוע יורד מהרשימה).

## אנשי קשר
- ייבוא: "יבוא אנשי קשר" (הדבקה עם כותרות או CSV); חובה טלפון או מייל. קבוצות (לכל קבוצה מספר).
- **מוסרים**: ברמת פריט קשר (טלפון ומייל בנפרד), טעינת מוסרים בטור אחד + שם מבצע וסיבה.

## דיוורים
- **דיוור עם מוצרים אוטומטיים מתג**: תג בקונימבו → במרקטינג "צור דיוור חדש" (שם, שולח, מייל, נושא + `|סיומת`) → תבנית ריקה → בלוק טקסט `[#konimbo_items#]` → בממשק קונימבו "יצירת דוא"ל הכולל מוצרים" → בחירת תג → עריכה → מזהה הדיוור + מספרי קבוצות (מופרדים בפסיק) → שליחה.
- **קופונים דינמיים**: כלים > קופונים > רשימה חדשה (תוקף, מקסימום לאיש קשר, התראה ב-80%/100%) → טעינת קודים בטור → פקד "קופון" באוטומציה (יציאות: תקין / מכסה הסתיימה / כבר הוקצה) → שילוב בהודעת SMS או בדיוור. קשור ל"קופונימבו".
- UTM אוטומטי: `utm_source=InforuMail&utm_medium=email&utm_campaign=<שם>`.

## אוטומציות (תהליכי אוטומציה > אירוע קונימבו)
- **נטישת עגלה**: אירוע מוגדר מראש → "שלח דיוור" עם תבנית נטישת עגלה (`[#cart#]` = קישור לסל) → פעיל. תנאים: לקוח **רשום ומחובר**, הגיע לעגלה עם מוצרים ונטש/הזמנה חלקית → מייל **~שעתיים** אחרי.
- **רישום לאתר / ברוכים הבאים**: אירועי "רישום לרשימת תפוצה" (ניוזלטר/פופאפ) ו"רישום לאתר" → תבנית "ברוכים הבאים" (+קופון).
- לאחר רכישה, פופאפ ייעודי לדיוור — סרטונים.
- **ברודקסט אוטומטי** (`admin/apps/automated_broadcast`): SMS מתוזמן שבועי; 5 סוגים — מוצרים חדשים / נצפים ביותר / נמכרים ביותר (תג דינמי לפי GA) / מבצעי השבוע (קישור לתג/קטגוריה) / קידום מוצר; עד 4 נוסחים רנדומליים, שם לקוח, אימוג'ים; יום+שעה; תאריכים מוחרגים (ימי זיכרון); UTM מותאם; שליחת בדיקה; "החלת תזמון".
