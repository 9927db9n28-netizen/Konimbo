# ניהול ועריכת מוצרים (134 מאמרים)

## מסך עריכת מוצר — לשוניות ושדות (↔ שדה API)
- **כללי**: כותרת* (`title`; משמשת ל-title, slug, פירורי לחם, H1; מבנה מומלץ "סוג + יצרן + דגם"), קטגוריה ראשית* (`store_category_title`; רק קטגוריות **בן**/סופיות),
  תיאור (`desc`, 2-3 משפטים, HTML מותר), זמן אספקה (`delivery_time`; ריק = הגדרות>כללי סעיף 4), אחריות (`warranty`), קטגוריות משניות (`secondary_category_titles`; אחת בכל שמירה),
  יצרן (`brand`; נשלף לכותרת), מק"ט ראשי (`code`), מק"ט משני (`second_code`, פנימי), תצוגה בחנות (`visible`), תצוגה במנועי השוואה (`zap_visable`), כותרת שונה לאתר מראה.
  ⚠️ מוצר בלי מחיר לא מוצג גם אם "תצוגה בחנות" מסומן; אי אפשר להציג במנועי השוואה מוצר שלא מוצג בחנות או שמחירו 0.
- **עריכת מפרט, תמונות ומסמכים** (מעל הלשוניות במוצר קיים): תמונות/PDF (מהמחשב או URL), alt לתמונה, מפרט טקסט חופשי (`spec_text`), **מפרט מובנה** (`spec`: מיקום/קבוצה/שם/ערך;
  מאפשר **דף השוואת מוצרים** — לשמור קבוצה+שם אחידים; יצירה מהדבקה: "ערך,שם,קבוצה" + "ערך מפריד" , + "יצירת מפרט מתוך טבלה ימנית"). תמונות 360°: alt=`item_360` (אחרי הטמעת אלמנט ע"י התמיכה).
- **מחיר**: מחיר (`price`), עלות (`cost`, פנימי; רווח בטבלה), מחיר לפני מבצע (`origin_price`, מחוק, שיווקי בלבד), מחיר לאתר מראה (גבוה ממחיר), מחיר אילת (`eilat_price`),
  מחיר כמוצר נלווה (`related_item_price`), מחיר ספק מומלץ (`restore_price`; **לא** בעדכון מחירים גורף), לינק חיצוני + מחיר מינימלי (לרובוט זאפ — עדיף להזין ברובוט > נסרקים),
  סוג מכירה (`only_contact`: V = "צור קשר" במקום קנייה; מחיר 0 = אוטומטית צור קשר; מחיר 0 + V = ניתן לקנות ב-0 — לשירותים/מכירה דרך שדרוגים בלבד), קפיצות כמות בק"ג (`quantity_step`; דורש דגל 90).
- **מכירה אישית** (`personal_sell`, `personal_sell_min_price`, `personal_sell_win_price`): מכרז — הצעות מעל מינימום נכנסות להזמנות, ≥ מחיר זכייה = רכישה; דורש רישום. בזאפ להוריד "הצג במנועי השוואה" כדי שיופיע רק כמכירה אישית.
- **מועדון**: הנחה/מחיר ספציפי למוצר לכל מועדון (`discount_prices` → `field_<id>`). **הנחות/קופונים**: "קבוצת קופון מספר" (`coupon_group_name`), "קבוצת הנחה מספר" (`discount_group_id`).
- **תשלומים**: תשלומים ללא ריבית (`free_payment`), מקסימום (`max_payment`), "ב.מ" = ברירת מחדל מהגדרות > כללי (סעיפים 0/1).
- **אייקונים** (`set_icons`): רק במוצר קיים; הצג בדף מוצר/קטגוריה, הפניה, כותרת (tooltip). אייקון חדש: הגדרות > תמונות וקבצים > יצירת אייקון (100×100).
- **מידע נוסף**: מידע נוסף (`content`; עורך עם תמונות — מועלות ב"תמונות וקבצים" `admin/images`, יוטיוב embed, MP4 דרך iframe), מאפיינים (`features`), קידום מכירה (`promotions` = "למה לקוחות קונים אצלנו": שורה ראשונה כותרת),
  הערכה כוללת (`kit`), מתאים לדגמים (`matching_models`). iframe דרך source code.
- **משלוחים**: ברירת מחדל (משויכים אוטומטית לכל מוצר חדש) / ייחודיים (ידני); חובה ≥1 משלוח; בדף המוצר מוצג המשלוח הזול ביותר. מחיר משלוח לזאפ (שיווקי).
- **שדרוגים**: סימון ערכים מתוך סוגי שדרוג. סוגים: סלקט, כמות לפי בחירה, כמות מ-עד, הנחת כמות, טקסט, טקסט ארוך, רדיו, צ'קבוקס, סלקט מותנה, קובץ, מתאריך-עד תאריך, מלאי. שדרוג = לא מוצר, שורה נפרדת בעגלה.
- **נלווים** (`related_items`): "עריכת מוצרים נלווים" (רק במוצר קיים; נלווה בלי מחיר לא יוצג), "מוצרים בחבילה (כולל ראשי)" — N-1 הנלווים הראשונים לפי מיקום = חבילה "מומלץ לקנות יחד", השאר בקרוסלה "לקוחות שקנו... קנו גם" (כותרת דרך **מילון החנות**). אבא לא יכול להיות נלווה ולא לקבל נלווים.
- **סינונים**: רק סינונים של קטגוריית המוצר. **תג**: הוסף/הסר. **אבא**: "מוצר אבא" (מחיר 0, להוריד ממנועי השוואה) / "אבא שלי הוא" — **חייבים אותה קטגוריה**; רכישה רק על בנים; לאבא כמה בנים, לבן אבא אחד.
- **גוגל**: title, description, keywords (גם משפרים **חיפוש פנימי**), slug — בהתייעצות עם מקדם. **פייפאל**: רק אם בהגדרות>כללי סעיף 21 בוטל "כל המוצרים מאופשרים" (22 ברירת מחדל, 23 מחמיר/לא מחמיר).
- **יתר**: כמות במלאי (`quantity` — פנימי, **לא יורד ברכישה**!), הערה (`note`, פנימי, מופיע בהזמנה), שם דגם (`model_title`), משקל (למשלוח לפי משקל, בק"ג), קבוצת צבע (`color_group` — טקסט זהה = "צבעי המוצר"),
  קוד גישה (`offer_code` → `/special_offers/<code>/<id>`, מוסתר מהאתר), וידאו יוטיוב (`video` = רק ה-ID), סוג מוצר (`zap_product_type`; ריק כדי לא לשלוף "מוצר חדש").
- **קוד**: `css_class`, `head_html`, `foot_html` (liquid). **בחר מלאי / ערוך מלאי**: שדרוג מלאי (הגדרות > מלאי > סוג מלאי חדש) ואז כמויות (`inventory`).
- **דיל עם טיימר** (דגל 91): מתאריך*/משעה/עד תאריך*/עד שעה/לופ/נמכרו/סה"כ למכירה/קטגוריה/אזור.
- לינקים ישירים: למוצר בחנות, שכפול מוצר, שכפול מפרט ותמונות, שכפול מפרט בלבד, מחיקה.

## מסך "כל המוצרים" (`admin/items?filter=all`)
סינון: הצג (מופיעים/לא/פח זבל/מנועי השוואה), קטגוריה, תג, יצרן, טווח מחיר, זמן אספקה, סיווג (אבא/בן/מכירה אישית/קבוצת צבע/דיל), נוצר לפני (עד 360 יום), קבוצת הנחה/קופון.
מיון לפי כותרות. עמודת "מיקום" = סדר בקטגוריה (מספר קטן = ראשון). רווח = עלות×מע"מ/מחיר.

## עדכון גורף (`admin/items/bulk_edit`) — הכלי המרכזי
- סינון ואז שדות ממוספרים (~30): 0 נקה קאש במוצרים; 2 זמן אספקה; 3 כמות בחבילה; 12 מחיקה/**שחזר מפח הזבל**; 15 קטגוריה משנית / תג (המספור משתנה בין גרסאות: תג 15/16); 19 נלווים ("הוסף את התג"); 19/20 אייקונים; 23/24 תיאור; 26 שדרוגים.
- **עד 250 מוצרים לכל עמוד/פעולה**. אחרי כל עדכון גורף נשלח **מייל עם קובץ גיבוי** (מוכן לטעינה, id + השדה) — לשחזור.
- נלווה לכמה מוצרים: תג עם הנלווים (עד 20) → עדכון גורף על המוצרים הראשיים → נלווים → הוסף את התג.
## עדכון מחירים גורף (`admin/bulk_prices/new`)
- שדה: מחיר/עלות/מחיר לפני מבצע/מחיר ספק מומלץ. חישוב: +%/-%/ביטול +%/ביטול -%/+₪/-₪/הכפלה/החלפה. עבור קטגוריה (אבא כולל בנים) ו/או תג ("כל המוצרים").
- "על בסיס שדה אחר": למשל להעתיק מחיר → מחיר לפני מבצע ואז להוריד מחיר (= מבצע). עיגול 0-1 ספרות. אישור בהקלדת שם השדה. נשלח קובץ גיבוי במייל.
- מנגנון בטיחות: "מקסימום ירידת מחיר בשקלים" (הגדרות > כללי סעיף 19).
## שחזור
עדכון גורף/מחירים → קובץ גיבוי במייל; CSV → לייצא לפני טעינה; **הגדרות > פעולות** = ארכיון קבצי גיבוי (אדמין); שחזור משרת — בתשלום.

## ייבוא/ייצוא מוצרים (CSV)
- ייצוא: הגדרות > תגים > "כל המוצרים CSV" (תג אחרון) > בחר פרמטרים > ייצא — הקובץ נשלח למיילים שבסעיף 29 "מיילים לעדכונים".
- טעינה: הגדרות > תגים > תג חדש > CSV > בחירת קובץ > ייבא. עמודות לדוגמה: `id`, `position`, `price`, `delivery_time`, `tag_category_titles`, `zap_product_type`, `data_record_<field>` (שדות נוספים).
- דגל 166 "save images with lambda" לטעינת תמונות מאקסל. דגל 121 — עד 40 תמונות.
## מיקומים בקטגוריית אב/בן
דגל 145 "מיין לפי קטגוריה משנית": כל בן = קטגוריה משנית, מיקומים קטנים בבנים; באבות מספרים גדולים (3000, 4000...) דרך CSV (`position`).

## כלים נוספים
- **מאגר ספקים דור 2**: הדבקת לינק מוצר מאתר ספק מאושר → משיכה אוטומטית (כותרת/מפרט/תמונות) → לתמחר. **click-it**: תוסף כרום למשיכה מרובה (אדמין ראשי + חשבון גוגל; מתנגש עם תוסף "רימון").
- **קרוסלת מוצרים משתנה** ("מוצרים בחנות"): לפי דף (מוצר/קטגוריה/תג/יצרן/עגלה/בית), תג עד 100 מוצרים, רק שדרוגי מלאי, דורש איחוד דומיינים.
- **העברת מוצרים בין חנויות קונימבו**: API בשתי החנויות (עימוד 300, 1000 קריאות/5 דק', items קריאה+כתיבה) + טריגר "transfare items" בחנות plugins.
- הגבלת כמות לרכישה: שדה נוסף `maxLimit` (CSV `data_record_maxLimit`), רק עם עגלה צפה.
- סכמת Google (schema.org): שדות נוספים דרך "אדמין קונימבו - מבנה נתונים" (sku, mpn, rating...). דגל "הסתר מחיר בסכמה".
- העתקת מוצרים מאתר אחר: canonical או שכתוב תיאור ומידע נוסף (חובה), שינוי קל בכותרת/מפרט.
- תמונה הפוכה מאייפון: לנקות EXIF (XnConvert).
