## עיצוב והייברידים (V2)
- **הייברידים (hybrid)** = רכיבי עיצוב/קוד ניתנים לעריכה בשדות (דרופ, הדר, פוטר...). מחפשים בשם באזור ה-hybrid.
- אחרי כל שינוי עיצוב: הגדרות > כללי > **"נקה קאש בחנות" פעמיים**.
- **הדר**: גודל/צבע פונט בסרגל, כמות קטגוריות בסרגל, אייקונים (טלפון, וייז, וואטסאפ, משלוחים).
- **דרופ V2**: הצגה, סוג, קבוצות, בורדר; עיצוב קטגוריות בן; תמונת אווירה / מוצר במבצע.
- **פוטר**: לשוניות — הגדרות כלליות (רקע/בורדר/טקסט), ניוזלטר (נרשם נפתח גם כלקוח + נכנס לפניות; כותרות; כפתור — תמונה מסתירה טקסט; צ'קבוקס), מפת אתר (לינקים דיפולטיביים + נוספים), קטגוריות ראשיות (נשלפות אוטומטית מהסרגל; 1-2 עמודות), צור קשר (ריק = נשלף מדף צור קשר), רשתות חברתיות (להסתרה: למחוק את ה-"/" מהלינק; fontAwesome), אחר (Google Map – src של iframe; דף פייסבוק — חייב להיות ציבורי).
- **מערכת המודולים** (סרגל ימני): קוביות תוכן; עיצוב קובייה (רוחבי לכל הקוביות), תכנים כלליים (כותרות עם רמת H1/H2/H3, כפתור+לינק, תמונות עם alt), עיצוב כללי (4 לשוניות); תצוגת מובייל נפרדת (תמונות שונות, 1-2 קוביות בשורה); **גרסאות קודמות** — שחזור דורס.
- דפים: **דפים > אודות**, **דפים > צור קשר** (טופס שם/טלפון/מייל/תוכן קבוע), **דפים > דפים נוספים** (תקנון, הצהרת נגישות, תקנון משלוחים).
- דף מותגים/יצרנים: הגדרות > סינונים רוחביים > עריכת דף היצרן (כותרת, תיאור, title/description/slug); לכל יצרן: הגדרות > יצרנים > עריכת דף יצרן.

## API לקופות NewOrder (מידע פנימי של קונימבו)
- קונימבו גובים 300 ₪/חודש על API לאינטגרציית NewOrder. התקנה אוטומטית: secure.konimbo.co.il/admin/apps/neworder_installation.
- ידני: הגדרה מתקדמת 155 = API, 210 = מלאי פנימי פעיל בעגלה; "משתמשי API" > משתמש חדש; כפתורים orders/items "use externally"; "מצא מוצר לפי" = id; הטוקן בלשונית "טוקן" בעריכת משתמש ה-API.
- שדרוג מסוג מלאי בשם "מלאי ניואורדר" עם class `quantity_upgrade`; מספר השדרוג מופיע ב-URL של עריכתו.

## עקרונות הצלחה (תוכן שיווקי של קונימבו)
4 יסודות: בידול, תקציב שיווק (רשתות, גוגל, זאפ, ניוזלטר, מועדון), ניהול שוטף (3-4 שעות ביום; "תמיכה" מול "צמיחה"), טכנולוגיה. UX: שימושיות, אסתטיקה, מהימנות (סמלי אבטחה), התמצאות (הדר סטיקי, חיפוש), נגישות, מידע בעל ערך; לבדוק נטישת עגלה.
