## עשרת הדברים החשובים ביותר
1. מוצר יכול לשבת רק בקטגוריה **שאין לה קטגוריות בן**.
2. המלאי יורד רק בתשלום מלא. השדה "כמות" בלשונית "אחר" הוא פנימי ולא יורד.
3. דרך ה-API, השדות images, related_items, spec, secondary_category_titles ו-related_tags **נדרסים במלואם**.
4. עריכה גורפת: עד 250 מוצרים בדף, ואחרי כל ריצה נשלח גיבוי למייל. זו הדרך הנכונה לשינויים מרובים בלי לבזבז קריאות API.
5. ב-API, הזמנות אפשר רק לעדכן סטטוס (להוסיף, עד 5). כל שינוי אחר נעשה בממשק.
6. מגבלת קצב: 100 קריאות ל-10 דקות. חסימה מחזירה 401.
7. בפורמט CSV יש עמודות שלא קיימות ב-API (ראו שיעור 05).
8. dynamica משתמשת בפונטים מותאמים: Roboto רק לסימן ₪, Poppins לאנגלית, ו-SimplerPro_V3 לכל השאר. הם נטענים מהיברידי S3.
9. PayPal: התעודה הישנה פגה באפריל 2026, והחדשה (app_cert.pem) תקפה עד 2036. אם PayPal הפסיק לעבוד, צריך לבדוק את ה-Cert ID.
10. מאמר 4000212997 (קישור סוכן) דורש התחברות לפורטל הסוכנים ולא נקרא.
